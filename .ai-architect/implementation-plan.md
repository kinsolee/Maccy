# 架构驱动的实施计划

## 已接受的决策

遵循 ADR-001 与 architecture-contract.yaml revision 2。用户在 2026-09-05 确认技术方案，并于 23:07:25 +08:00 明确“UI用第 1 张作为任务目标”。架构和 UI 均获批准，可以开始原生应用编码。不要把本交接文件视为提交、发布或修改全局配置的授权。

## 里程碑

### 1. 独立存储与最小文本闭环

范围：Storage、独立 PresetGroup/Preset/PresetContent 模型、单一 PresetLibrary。
同一 ModelContainer 内使用专用 ModelContext，关闭预设上下文自动保存；所有预设读写通过所有者。编辑采用值草稿，显式保存，失败只回滚本上下文并保留草稿。Presets 不保存 title，不复用 HistoryItemContent 实例。删除组解除关系，保留未分组内容。排序采用稳定保存顺序，不新增拖拽排序能力。

验证：使用明确标注的合成临时磁盘存储覆盖旧历史和固定项迁移、重开后预设完整、历史 clear/clearAll 不影响预设、非空组删除保留内容，以及预设保存失败后历史保存和重启不会带入弃用草稿。保留真实用户数据库。

### 2. 同一窗口内选择与管理

依赖：UI Q-001 已解答、里程碑 1。
范围：ContentView、Header、历史/预设行、NavigationManager、AppState、Popup、KeyHandlingView、FloatingPanel 的子窗口行为。
顶部历史固定第一、用户分组和末尾加号；现有快捷键唤起同一窗口。只记稳定分组 ID；查询按当前组过滤。一个明确的当前选择目标区分历史、预设、footer 和现有粘贴栈。恢复与删除时清除过期选中。手动新增、编辑、删除在当前窗口完成，无标题输入。普通项遵循现有复制/粘贴偏好。预设仅单选，不允许跨范围混选；历史多选保留原行为。固定及历史清空命令不得作用于预设。

验证：键盘与鼠标选择一致，切组和过滤不发送旧内容；IME Enter/Esc 正确；保存、取消、新建组和删除均不写剪贴板或发送事件；辅助功能按钮可访问。检查子窗口打开不会意外关闭父面板，焦点恢复不会误发。

### 3. 拖放保存与完整内容搜索

范围：历史行拖拽、组标签 drop、统一搜索和显示摘要。
仅使用应用内可验证的拖拽标识，捕获历史内容值快照；校验目标存在，每次 drop 只保存一次。拖拽开始退出 cycle、冻结 hover、使旧发送回调失效；结束和取消也不得恢复旧回调。保存后仍留在历史。需要完整生命周期时局部使用 AppKit 回调，不引入通用状态机。

搜索读取真正的完整正文，不能使用截断后的 decorator.text/title。搜索快照携带匹配范围；摘要和高亮从同一快照生成、按命中片段重新映射。明确处理现有 fuzzy 截断，不能声称全文搜索却漏掉后半段。保留旧固定项标签和已有图片 OCR 搜索行为。

验证：重复 drop、取消、历史删除/目标组变化及旧异步回调不重复保存或误粘贴；保存失败无成功提示。覆盖 500/5000/10000 字符后的正文、换行、emoji、组合字符，以及查询后内容变化；匹配、高亮和原始粘贴内容一致。

### 4. 图片与独立文件副本

范围：PresetLibrary 附件导入、Clipboard 的最小类型化内容入口、目标应用验收。
图片持久化可读实际字节，覆盖通用剪贴板图片需要由 URL 读取数据的现有例外。手动文件选择沿用 macOS 授权；普通文件完整复制到专属暂存目录，完成后移入独占最终目录，再保存记录；失败清理本次新建目录。大文件使用文件复制，不整段读取进 Data；允许取消。
文件路径相对应用附件根目录记录并保留原文件名、明确顺序；不加入共享附件去重、引用计数或自动回收框架。删除预设先成功删记录，不删除原文件；保守保留已经用于剪贴板的副本。目录、文件包、符号链接不自动视为独立普通文件副本。

验证：文本到 TextEdit、受控 Chrome 输入；图片到可接收图片的应用；文件到 Finder 和代表性目标应用。使用合成素材，源文件移动/修改/删除后重启，再粘贴并核对文件数量、顺序和内容哈希；覆盖同名、中文名、空格、大文件与视频。确认沙盒跨应用读取实际可用。权限缺失、源消失、磁盘不足和导入取消不能产生可见半成品。视频只按文件验收。

## 横向约束

- 同一工作区同一时间一个写入者；保留用户改动；不提交或推送。
- 不引入新依赖、第二个管理窗口、第二个数据库或通用 Provider。
- 普通管理动作不得写剪贴板。明确发送预设前中断已有粘贴队列，但不把中断操作放进队列自身复用的基础写入函数。
- 复用 Clipboard 的文件 writeObjects 和其他类型 Data 路径；不得临时创建 HistoryItem 来发送预设。来源标记与 changeCount 同步防止自动写回历史。
- 权限不足明确提供复制/系统设置路径；不得静默重试。粘贴前及关闭面板后检查原目标应用仍存活且仍在前台，应用改变或不可用时拒绝自动发送。按2026-09-06用户批准的paste-recovery-v1，不跨进程读取AX窗口；同一应用内部的窗口切换不再校验，沿用原Maccy向当前输入目标粘贴的行为。
- 区分 unit verified、snapshot verified 与 live verified；模拟键盘事件或剪贴板写入成功不代表接收方已实际插入。
- 完成后由独立审阅检查实际 diff 与证据；主代理完成集成和运行验收。

## 明确不做

云同步、每个条目/分组独立热键、模板变量、预设自定义标题、跨组搜索、组间拖动和排序、新增图片 OCR、视频编辑器片段支持、文件自动去重和垃圾回收。
